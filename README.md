# Hyatus Stays

Find furnished Hyatus stays, read public listing details, check local dates and prices, and compare homes. Open Hyatus.com to complete checkout.

## Test in Cursor

```sh
git clone https://github.com/Hyatus-Living/hyatus-stays.git "$HOME/.cursor/plugins/local/hyatus-stays"
```

Reload Cursor and open **Customize** to find the Hyatus Stays plugin and its `hyatus-stays` MCP server. The server uses public stay data and connects without a Hyatus account or API key.

## Install in Gemini CLI

```sh
gemini extensions install https://github.com/Hyatus-Living/hyatus-stays
```

For another MCP client, use `https://www.hyatus.com/api/stays/mcp` with Streamable HTTP. Public stay reads use anonymous access.
